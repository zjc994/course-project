# 英雄试炼

这是一个使用 PyQt5 编写的回合制英雄战斗小游戏。玩家先在选择界面把基础蘑菇放到舞台上，再通过武器派生出战士、弓手和法师，组成三人小队挑战熔岩领主。

## 运行环境

- Python 3.8 或更高版本
- PyQt5

安装依赖：

```powershell
python -m pip install PyQt5
```

## 启动游戏

进入项目目录后运行入口文件：

```powershell
cd D:\cpp-practice\course-project-main
python main_window.py
```

如果从仓库根目录运行，请先切换到包含 `images` 文件夹的目录。游戏中的图片资源使用相对路径加载。

## 玩法说明

1. 在开始界面点击开始游戏进入英雄选择界面。
2. 将基础蘑菇拖到三个舞台上。
3. 将武器拖到舞台上的蘑菇身上进行派生：
   - 剑：派生为战士，生命值高，可以给队友提升攻击力。
   - 弓：派生为弓手，擅长群体攻击，可以给队友附加反伤效果。
   - 法杖：派生为法师，可以攻击敌人，也可以治疗队友。
4. 三个舞台都放置已派生英雄后，点击开始战斗。
5. 战斗中将英雄拖到敌人身上发动攻击，将英雄拖到队友身上释放辅助技能。
6. 每名英雄每回合只能行动一次，全部行动完成后进入敌人回合。

## 其他功能

- 帮助按钮：查看游戏介绍和操作说明。
- 镜子：复制已派生英雄，可选择深拷贝或浅拷贝。
- 垃圾桶：删除已放置英雄。
- F11：切换全屏。
- Esc：退出全屏。
